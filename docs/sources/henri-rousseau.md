# Henri Rousseau — The Repast of the Lion (c. 1907, The Met)

Internal sources list for `src/content/stories/henri-rousseau.ts`. Each line of copy maps to a row below.

**Research note (12 Oct 2026):** this pass ran through a sandbox that could search the web but couldn't open museum pages directly (Met site and API did not resolve). Rows marked **re-check** were confirmed from search-result excerpts only. Open each source page and confirm the row before launch.

**Work:** The Met, object 438822, accession 51.112.5. Oil on canvas, 113.7 x 160 cm. Bequest of Sam A. Lewisohn, 1951. Dated ca. 1907. The Met says it was *probably* shown at the 1907 Salon d'Automne, so the copy doesn't claim that. Image: `public/art/w800/henri-rousseau.jpg` (800 x 563), set as 1600 x 1126. The documented canvas ratio (1600 x 1137) is close; the file ratio was used as instructed. Focus points checked against this Met image.
