# Amedeo Modigliani — Reclining Nude (1917, The Met)

Internal sources list for `src/content/stories/amedeo-modigliani.ts`. Each line of copy maps to a row below.

**Research note (12 Oct 2026):** this pass ran through a sandbox that could search the web but couldn't open museum pages directly (Met site did not resolve). Rows marked **re-check** were confirmed from search-result excerpts only. Open each source page and confirm the row before launch.

**Work:** The Met, object 486847, accession 1997.149.9. Oil on canvas, 60.6 x 92.7 cm. The Mr. and Mrs. Klaus G. Perls Collection, 1997. Provenance (Met): Léopold Zborowski; Georges Menier; Claude Menier; dealers; Mr. and Mrs. Klaus G. Perls (until 1997). Not on view at time of search. Image: `public/art/w800/amedeo-modigliani.jpg` (800 x 536), set as 1600 x 1072. Focus points checked against this Met image.

**Show link:** no source found says this canvas was in the December 1917 Berthe Weill show. The work most often linked to the show is a different *Nu couché* (Liu Yiqian), and even that is "believed". So the copy connects the show to Zborowski and to 1917, never to this painting.
