# Gustav Klimt — The Kiss (1908/09, Belvedere, Vienna)

Internal sources list for `src/content/stories/gustav-klimt.ts`. Each line of copy maps to a row below.

**Research note (11 Oct 2026):** this pass ran through a sandbox that could search the web but couldn't open museum pages directly. Every row is confirmed from search-result excerpts only, so every row is **re-check**. Open each source page and confirm the row before launch.

**Work:** *Kuss (Liebespaar)*, 1908/09. Oil and gold leaf on canvas (silver and platinum in the figures), 180 x 180 cm. Belvedere, Vienna. Image aspect 1600 x 1600. Most sources date it 1907–08; the Belvedere gives 1908, completed 1909. The copy uses 1908 (the year it was shown and bought).
