# Artemisia Gentileschi — Judith Slaying Holofernes, Uffizi version (c. 1620)

Internal sources list for `src/content/stories/artemisia-gentileschi.ts`. Each line of copy maps to a row below.

**Version:** this story uses the **Uffizi, Florence** painting (c. 1620, inv. 1890 n. 1567), her second treatment of the subject. The earlier version (c. 1612–13) is at the Museo di Capodimonte, Naples. The cover kicker says "Uffizi version".

**Research note (11 Oct 2026):** this pass ran through a sandbox that could search the web but couldn't open museum or Wikimedia pages directly. Rows marked **re-check** were confirmed from search-result excerpts only, not from the source page itself. Open each source page and confirm the row before launch.

**On the trial:** the close beat states only documented facts of the 1612 proceedings (who brought the case, the charge, the thumbscrews, the verdict, the unenforced sentence). It doesn't read the painting as revenge or autobiography. That reading is common in criticism, but it is interpretation, not documented fact, so it stays out.

## Kept out of the copy

- **"It is true, it is true, it is true"** (her words under the thumbscrews): documented via the trial transcript as reported in secondary sources (Breach Theatre's verbatim play; Friedlein). No primary transcript or scholarly edition checked this pass, so it is not the quote. It could replace the signature once confirmed against an edition (e.g. Garrard, *Artemisia Gentileschi*, 1989, appendix).
- **Galileo's ballistics shaping the blood arcs:** speculative (Artnet *Art Bites*; artlark). **Weak**, dropped.
- **Cosimo II disliked the painting and kept it out of sight:** one excerpt only. **Weak**, dropped.
- **Bracelet medallions depicting Artemis:** not confirmed this pass. Dropped.
- **Dimensions disputed:** the Uffizi page (via search excerpt) gives 146.5 × 108 cm; Wikipedia and others give about 199 × 162.5 cm. The image ratio uses the Uffizi figure. **Re-check before the image is cropped.**
- **Marriage to Pierantonio Stiattesi** (29 Nov 1612) and the move to Florence (dates disagree: late 1612 / 1613 / 1614). Not needed.
