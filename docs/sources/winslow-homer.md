# Winslow Homer — The Gulf Stream (1899, reworked by 1906, The Met)

Internal sources list for `src/content/stories/winslow-homer.ts`. Each line of copy maps to a row below.

**Research note (12 Oct 2026):** this pass ran through a sandbox that could search the web but couldn't open museum pages directly (Met site did not resolve). Rows marked **re-check** were confirmed from search-result excerpts only. Open each source page and confirm the row before launch.

**Work:** The Met, object 11122, accession 06.1234. Oil on canvas. Dated 1899, "reworked by 1906". Catharine Lorillard Wolfe Collection, Wolfe Fund, 1906. First exhibited at the Pennsylvania Academy of the Fine Arts, 1900. Image: `public/art/w800/winslow-homer.jpg` (800 x 489), set as 1600 x 978. Focus points checked against this Met image.

**Letter note:** Homer's reply to M. Knoedler & Co. calls the sailor by a racial slur ("the unfortunate negro who now is so dazed & parboiled…"). The copy paraphrases the rescue line without quote marks and doesn't reproduce the slur. Sources disagree on the date: usually 1902 (when Knoedler showed it and some women visitors asked), one says after the 1900 PAFA show. So the copy doesn't date the letter.
