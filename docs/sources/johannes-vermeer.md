## Kept out of the copy

- **Dimensions:** Wikipedia and The Collector give 44.5 × 39 cm; some Wikimedia file pages give 46.5 × 40 cm. The image ratio uses 44.5 × 39. Confirm on the Mauritshuis page.
- **Modern value of the 1881 price:** Wikipedia says about €24 (2015); IamExpat says about €30. Disagree, so left out.
- **Composition changes** (ear, scarf top and nape shifted): found in one excerpt (Jakarta Post / AFP). Not needed.
- **Lapis lazuli as the source of the ultramarine:** standard, but not confirmed in this pass, so the copy just says "costly".
