## Hooks found but not used

- **The burned Opéra.** The Met's text on its 1874 *Dance Class* says the room is set in a rehearsal room of the old Paris Opéra (rue Le Peletier), "which had recently burned to the ground". That's the best hook for this subject: Degas painting a room that no longer existed. But this pass couldn't confirm the fire date (believed to be October 1873), or whether the Orsay version is set in the same room. **weak**: one source, and possibly about the other version.
- **Jean-Baptiste Faure.** The singer Faure commissioned one of these pictures, lent it to the 1876 Impressionist exhibition, and a Rossini poster by the mirror is a nod to him. Search results tied this to the Met's text, but it wasn't clear which version it was about. **weak**: kept out until it's matched to the right canvas.
- Watering can, dog, dancer scratching her back: commonly described details, not verified this pass. Kept out.

If the next pass can confirm the burned-Opéra detail for one version, consider switching the featured work to that version and rebuilding the story around it.
