# Edvard Munch — The Scream (1893, National Museum, Oslo)

Internal sources list for `src/content/stories/edvard-munch.ts`. Each line of copy maps to a row below.

**Research note (11 Oct 2026):** this pass ran through a sandbox that could search the web but couldn't open museum pages directly. Every row is confirmed from search-result excerpts only, so every row is **re-check**. Open each source page and confirm the row before launch.

**Version chosen:** the 1893 painted version, Nasjonalmuseet (National Museum), Oslo, NG.M.00939. 91 x 73.5 cm, on cardboard (sketch for The Scream on the reverse, NG.M.00939VERSO). Image aspect 1292 x 1600. Medium is disputed between sources (tempera and crayon vs oil, tempera, pastel and crayon), so the copy doesn't name it. Sold 1910 to Olaf Schou, who gave it to the National Gallery.

**Other versions (not this page):** 1893 crayon (Munch Museum); 1895 pastel (private; sold 2012); 1910 tempera (Munch Museum, the one stolen in 2004); plus the 1895 lithograph. Check this list against the Munch Museum before using it anywhere in copy.
