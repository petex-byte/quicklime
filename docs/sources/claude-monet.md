# Claude Monet — Water Lilies: Green Reflections (c. 1915–26), Musée de l'Orangerie

Internal sources list for `src/content/stories/claude-monet.ts`. Each line of copy maps to a row below.

Featured work: *Les Nymphéas: Reflets verts* (Water Lilies: Green Reflections), oil on canvas, 200 x 850 cm, Musée de l'Orangerie, Room 1, east wall, INV 20102. One panel of the Orangerie cycle. The story is the cycle's story (gift, contract, rooms, 1944), anchored on this panel.
