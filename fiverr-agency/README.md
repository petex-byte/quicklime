## Launch order

1. Lock the name. Check Fiverr username, domain and Instagram handle.
2. Paste `agency_bio.txt` into the profile. Add one real photo of both of you.
3. Publish Gig 3 and Gig 4 first: fastest to deliver, fastest to earn the first reviews.
4. Render Video 1 (UI/UX reel) from the storyboard. Publish Gig 1 and Gig 2.
5. Publish Gig 5 once you've run the SOP end to end on your own brand as a test order.
6. Put the subdomain live last. It links to Fiverr, never the other way round.
